# Dungeon-game
Hello, this is my demonstration project.
## In this project, I have implemented:
* A movement system with a smooth increase in speed while running
* The health system of the player and enemies, as well as the system of receiving
  and dealing damage
* A system of the simplest enemies and obstacles
* Item collection system
* The collision system
* The death system
* location switching system with saving player stats
* Main menu with working buttons "start" and "exit" and animated title
* Loading screen with animated text
* The final screen
* The GUI system
* Hint system
* Animations
* Sound and music system
## If you want to play it yourself, then here are the keys to control:
* Moving: W, A, S, D
* Sprint: Left Shift
* Attack: SPACE
